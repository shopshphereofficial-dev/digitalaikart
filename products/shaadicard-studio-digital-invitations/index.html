The Problem It Solves

What usually goes wrong with a digital invite

Every edit costs money or a subscription

Designers charge per revision, and Canva locks the good templates behind a monthly plan. A wedding has a hundred small changes — a time moves, a venue changes, a cousin is added to the sangeet. This is one payment and unlimited edits.

A pretty invite that tells guests nothing

Half the messages after the invite goes out are "where exactly is it?" and "what time is the mehndi?". Every function in this invitation carries its own venue and a one-tap Maps link, and every guest can add all of it to their calendar in one click.

RSVP by "please confirm on this number"

Guests forget, or reply to a different cousin. The RSVP button opens WhatsApp with the message already written and addressed to the number you chose, so confirmations arrive in one place, in one format.

An invite that only works on Instagram

A story disappears in 24 hours and a link sticker does not work for everyone. A hosted invitation page is a link you can put in a bio, a WhatsApp forward, a printed card's QR code or an email — and it still works next month.

Uploading family photos to another website

Invitation builders want your photos on their servers. Here the studio never makes a network call: the invitation is built on your own laptop and you decide where it is hosted.

An invite that prints badly

Screen designs usually waste a page when printed. The same file carries a print stylesheet that produces one A5 card with the essentials and none of the buttons — so one design covers the WhatsApp link and the card handed out at home.

How It Works

Four steps, one evening

Unzip the folder and double-click shaadicard-studio.html. It opens in Chrome, Edge, Firefox or Safari. Nothing to install, no account, no internet needed.

Names, host line, date and time, venue. Add each function with + Add. Paste photo links if you have them, and your WhatsApp number for RSVP.

3 · Pick a design and check the preview

Switch between Classic Gold, Midnight Bloom and Marigold. Use the Phone / Tablet / Desktop buttons to see exactly what guests on each screen will get.

4 · Download, host, share

Press Download invitation. Rename the file, drag it into Netlify Drop or your host, and share the link on WhatsApp. Print the same file as an A5 card when you need paper.

Frequently Asked Questions

Everything you need to know before buying

Is this an invitation template or a tool?

A tool that produces the template. You open one HTML file, fill a form with your names, dates and venues, choose one of three designs, and press Download. What you get is a finished, self-contained invitation page you can host anywhere or print as a card. You never edit code unless you want to.

Do I need Canva or a subscription?

No. Nothing is locked behind a Canva plan and there is no monthly fee. The designs, fonts and layout ship inside the file, and the fonts are ones already installed on the guest's device — so an invitation never asks a guest to install anything or load a web font.

Does the invitation work on a phone?

The invitation you download is mobile-first and works on any phone. The maker itself is a desktop tool — editing on a laptop or desktop is much easier because the form and the live preview sit side by side. Make it once on a laptop and share the finished file with everyone.

How do guests RSVP?

The RSVP button opens WhatsApp with a message already written and addressed to the number you entered, so replies land in your WhatsApp. There is no form, no server and no third-party RSVP service to sign up for. You can also print the number on the card.

Where do I host the invitation?

Anywhere that serves a static file. Drag the file into Netlify Drop for a free link in seconds, upload it to GitHub Pages, or put it on your existing domain. You can also send the file directly on WhatsApp or email, though a hosted link gives clickable RSVP buttons and a proper preview.

Can I change the invitation after I have shared it?

Yes. Open the studio, change the details, download again and upload the new file to the same place. The link stays the same, so nothing you have already shared breaks.

How many invitations can I make?

As many as your family needs — one per function, one per cousin, one per year. The licence covers your own and your family's events. Reselling the tool, or selling invitation design as a service, needs a separate commercial licence.

Does the countdown show the right time?

The countdown runs on each guest's own device clock and counts to the exact date and time you typed. Enter the time in Indian Standard Time for guests in India; if you have guests abroad, add the time zone to the venue line so nobody has to guess.

Can I print it as a physical card?

Yes. The file carries a print stylesheet that lays out a single A5 card — names, date, venue, function list and hashtag — with the countdown, buttons and gallery removed automatically. Print with background graphics turned on, or hand the PDF to a printer.
