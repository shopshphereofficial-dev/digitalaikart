What's Inside

Six things most people only learn the hard way

Frequently Asked Questions

Everything you need to know before buying

Is this useful if I have already resigned?

Yes. Most of the playbook is about what happens after the letter — the settlement, gratuity, EPF, relieving letters and what to do when payment is late. If your last working day has already passed, start at Chapter 6 and Chapter 15.

Is this legal advice?

No. It is a practical guide that tells you what the statutes, rules and court judgments say, with every source listed in Chapter 20 so you can check it yourself. For a dispute that has already turned adversarial, you still need a lawyer.

What is new in the 2026-27 edition?

It is built around the four Labour Codes, which came into force on 21 November 2025. That includes section 17(2) of the Code on Wages, which requires wages on resignation to be paid within two working days, and the 50% allowance rule that raises the wage base used for gratuity. Both are explained with worked numbers.

Will it work for my state and my company?

The central statutes apply across India, and the guide flags where state Shops and Establishments rules still govern. Your own appointment letter always decides the notice period, so Chapter 2 teaches you how to read it — that part works for any employer.
