Frequently Asked Questions

Everything you need to know before buying

Is this an ebook?

No. You get a working label maker — an app you open in your browser — plus instructions, sample files and a licence. There is no book to read.

Do I need internet or an account?

No. Everything runs from the folder on your own computer. There is no sign-up, no login, no server and no analytics, so you can switch off the internet and keep printing.

Will the barcodes scan at my counter?

Code 128 and EAN-13 are generated to the published specifications, and every sample was decoded back with an independent barcode reader during testing. Whether a particular label scans depends on your printer, paper and scanner — print one test label and scan it before a full batch.

Which barcode type should I use?

Code 128 by default: it holds letters, numbers and dashes, so your own SKU like TATA-SALT-1KG works. Use EAN-13 only if you have a real 13-digit number, for example from a supplier. EAN-13 accepts digits only and TagCraft calculates the check digit for you.

How does the UPI QR work?

You enter your UPI ID once. TagCraft builds a standard upi://pay link with your ID, your shop name and the label's price, and prints it as a QR code. The customer scans it with any UPI app and pays you directly. The money never passes through TagCraft and no payment credentials are stored.

Which label sheets are supported?

Five layouts: A4 with 24 labels (63.5 x 33.9 mm), A4 with 40 labels (48.3 x 25.4 mm), A4 with 14 labels (99 x 38.1 mm), a 50 x 25 mm roll and a 38 x 25 mm roll. Positions are exact for the standard A4 sticker sheets sold in India.

My sticker sheet is half used. Can I print on the remaining part?

Yes. Set 'Start at position' to skip the labels you have already used; those slots print blank and the first product starts where you tell it to.

Can I import my existing product list?

Yes. Import a CSV with the columns name, price, mrp, code, size, copies — the same file you already keep in Excel works. You can export the list back to CSV at any time, and save the whole project as a JSON file to move it to another computer.

Does it print a GST invoice?

No. TagCraft prints price and payment labels only. It does not create tax invoices or file returns — for invoices use a billing or GST tool.

Which printers and computers does it work on?

Any current Chrome, Edge, Firefox or Safari on Windows, macOS, Linux or Android, with any printer that can print A4 or a label roll. Printing from a phone needs a printer app or a wireless printer.

How do I get the files after payment?

After a successful payment on Razorpay you land on a thank-you page with a download button. The ZIP downloads immediately and the link stays usable — keep the email receipt.
