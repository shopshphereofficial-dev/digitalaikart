Claude Code Projects: Run a Team of AI Agents in the Cloud

TL;DR

  • Anthropic has relaunched Projects inside Claude Code — you can now run multiple AI agents under one roof with shared memory, goals and files
  • Parallel "threads" each work on their own branch and copy of the repo; a coordinator agent keeps everything organised
  • Overlapping work is resolved as a normal merge conflict — like any pull request
  • Beta is live for select Claude Pro and Max subscribers; wider rollout and local support coming

Anthropic has quietly shipped one of the most practical AI releases of the month: a revamped version of Claude Code Projects that lets you manage a whole team of AI agents in the cloud instead of chatting with one assistant at a time. If you've been following the agent wave — like when we wrote about Zed's Delta agents replacing pull requests — you'll know this is where the entire industry is heading. Anthropic just made it considerably more concrete.

01.Claude Code Projects: what actually launched

The idea is simple to describe and big in consequence. A Project in Claude Code now runs multiple agents that all coordinate with each other — sharing one memory, a common set of goals, and a shared library of files and artifacts. Each project contains "threads" running different tasks in parallel, and above them sits a "coordinator" that directs everything.

You can talk to each thread individually when you want to nudge one specific task, or monitor and steer everything through the main project chat. It's less "chatbot" and more "project manager with a staff that never sleeps."

02.Branches, merge conflicts and why the design is clever

Under the hood, each thread is a Claude Code cloud session working on its own branch and its own copy of the repository. The coordinator keeps the work organised, but if two threads touch the same code, the overlap is resolved as a merge conflict — exactly like any pull request. Any thread can also split its own delegated work into smaller pieces using subagents, loops and workflows when a large assignment needs to finish faster.

Honestly, what surprised me most is how unglamorous the design is — in the best way. Anthropic didn't invent a new "agent protocol"; they leaned on the version-control workflow every developer already knows. If you've ever resolved a Git conflict, you already understand how to supervise this thing.

03.Availability: who gets it, and when

At launch, threads run in the cloud, and Anthropic says support for local tools and code is coming "very soon." The beta is available starting today for select Claude Pro and Max subscribers, with access expanding to all Pro, Max, Team and Enterprise users later — and eventually to Cowork and regular Claude chats as well.

No India-specific pricing was announced, but Pro plans have historically been the affordable entry point for Indian students and freelancers, and the Pro tier is where this lands first. If you're already on Pro, keep an eye on your account over the next few weeks.

04.What this changes for developers and freelancers

Here's the thing nobody's talking about: until now, running multiple agents meant juggling tabs, copy-pasting context between windows, and hoping nothing collided. That overhead is exactly what killed most DIY "agent team" setups. A shared memory plus automatic merge-conflict resolution removes both problems in one stroke — the agents literally pass files to each other through the project's shared library.

For a one-person freelance shop in India, this is the shape of a whole new service model: one developer, five parallel agents, and a delivery pipeline that used to need a small team. The bottleneck shifts from writing code to reviewing and directing it — which is precisely the skill gap worth closing this year.
